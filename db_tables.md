## Products Table

Stores all of the products offered in DuckMart.
 

| Column Name | Description |

|-------------|-------------|

| Product ID | Unique Identifier |

| Name | Name product is listed as |

| Image | link to image of product |

| Category | Group such as "bakery", "deli", etc. |

| Price | selling price |

| Stock | Number of items in stock |

| On Sale | Yes or No value. If yes, product will be displayed at a discount and shown in the 'Deals' section of website |
